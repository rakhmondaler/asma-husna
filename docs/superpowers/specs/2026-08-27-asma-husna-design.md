# Аль-асма аль-хусна — дизайн проекта

Дата: 2026-08-27. Статус: согласован с Далером в сессии, ждёт финальной проверки по тексту.

## Что это

Интерактивный сайт о 99 именах Аллаха: толкования, примирение кажущихся противоречий, интересные факты. По духу — родственник «Philosophical Cosmos» (философская карта Далера), но без графа связей и без системы координат. Стержень — не пространство, а путь: одно имя за раз, как перебирание чёток.

## Сцена

- Тёмный фон, той же породы, что космос карты философов.
- Через весь экран слева направо протянута нить чёток (мисбаха) с лёгким провисанием — реалистичная 3D-визуализация на Three.js (WebGL).
- 99 янтарных бусин: полупрозрачный материал с внутренним свечением, живые блики, физически корректный свет.
- Канон формы: плоские разделители после 33-й и 66-й бусины, кисточка у застёжки. Форма несёт смысл: тасбих читается по третям (33 + 33 + 33).

## Механика

- Текущая бусина — в центре, чуть крупнее, светится ярче.
- Листание (стрелки, свайп, колесо мыши) — нить протягивается: бусины сдвигаются, следующая встаёт в центр. Чтение = перебирание чёток.
- Клик по любой бусине — переход к её имени.
- Прогресс сохраняется в localStorage: вернулся — продолжил с той же бусины.
- Парные имена: вторая бусина пары тоже загорается на нити; карточка раскрывается диптихом.

## Карточка имени

Под чётками, для текущего имени:

1. Арабская вязь крупно.
2. Транслитерация.
3. Варианты русского перевода; где переводы спорят — показываем оба и объясняем расхождение.
4. Толкование с опорой на аль-Газали («аль-Максад аль-асна» — классический трактат о 99 именах).
5. Один интересный факт: этимология, место в Коране, абджад (числовое значение букв).
6. Сноска, если имени нет в одном из канонических списков (состав у ат-Тирмизи и Ибн Маджи различается).

Для парных имён (аль-Мухйи/аль-Мумит — Оживляющий/Умерщвляющий; аль-Кабид/аль-Басит — Сжимающий/Расширяющий и др.) — диптих: два имени рядом и текст о том, как традиция примиряет полюса. Противоречия — главный сюжет проекта, расхождения списков и переводов — честная сноска.

## Данные и техника

- Статика без сборки: `index.html`, Three.js с CDN (ES modules), `data/names.json`.
- Схема записи в `names.json`: `id` (1–99), `arabic`, `translit`, `translations[]` (вариант + примечание о расхождении), `tafsir` (толкование), `fact`, `pairId` (id парного имени или null), `pairText` (текст примирения, у одного из пары), `listNote` (сноска о списках или null), `abjad` (число).
- Деплой: Vercel (аккаунт rakhmondaler), репозиторий GitHub `rakhmondaler/asma-husna`.

## Визуальные правила (перенесены из карты философов)

- Минимализм и монохромная дисциплина: янтарь на тёмном — единственная тёплая нота, без пёстрых кодировок.
- Никаких обучающих оверлеев и онбординг-хинтов поверх сцены: сцена должна быть понятна сама по себе.

## Этапы

1. **v0 — каркас.** Сцена чёток целиком (99 бусин, разделители, кисточка, свет, листание, клик, localStorage) + контент первых 9 имён, включая минимум одну пару для проверки диптиха. Далер смотрит, правим повадку.
2. **v1 — полный контент.** Остальные 90 имён, вычитка, деплой.

## Вне рамок (пока)

- Режим «имя дня» — возможная опция позже, не в v0/v1.
- Аудио (произношение имён), поиск, шаринг отдельных имён.
