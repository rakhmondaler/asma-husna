# Аль-асма аль-хусна — роадмап

Живой план проекта. Здесь фиксируем фичи и триажируем их по стоимости
реализации в токенах. Перед началом любой работы — сверяться с этим файлом
и обновлять статусы.

## Статус на сегодня (август 2026)

**В проде (v1)** — https://asma-husna.vercel.app:

- все 99 имён с толкованиями (по аль-Газали), фактами и сносками о расхождениях списков
- 10 пар-диптихов с текстами примирения полюсов
- чётки замкнуты в кольцо: за кисточкой снова первая бусина, навигация по кругу
- сцена v1: янтарные 3D-бусины (Three.js), разделители после 33/66, листание, клик, localStorage

**Решено делать — редизайн v2 по эскизу Далера:**

- малахитовые бусины-спрайты из PNG (4 варианта камня + случайный поворот ±25°)
- видеофон-космос (ProRes 1,5 ГБ сжат до 6 МБ, 1080p H.264)
- эмблема руб аль-хизб из Figma-слоёв: звёзды с blend-режимами (soft-light, overlay), розовое свечение, медленное вращение на 360°
- каллиграфия текущего имени в эмблеме: сначала шрифтовая, потом покупная или отрисованная SVG (слот `assets/calligraphy/1.svg…99.svg`)
- белые карточки: имя + перевод + аят + бейдж номера + кнопка «Узнать больше»
- полноэкранная страница имени с полным контентом (толкование, факт, пары, сноски)
- зелёная кисточка из PNG, вверх от нити, как в эскизе

## Правила триажа

1. Сначала S-фичи, которые закрывают видимые дыры. Потом M по приоритету Далера.
2. L-фичи — только по явному решению Далера, не по инициативе исполнителя.
3. Перед каждой фичей — свериться с этим файлом; после — обновить статус.
4. Новые идеи сначала попадают сюда со статусом «идея», а не в код.
